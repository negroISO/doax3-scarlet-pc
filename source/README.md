# DOAX3 Scarlet: shared runtime source

Start with the [repository README](../README.md) and [build instructions](../docs/building.md).
The supported launchers and project.json are at the repository root.

This source snapshot contains the native x86-64 runtime, shadPS4-derived Vulkan
graphics core, DOAX3 fixes and vendored dependencies used by this edition.
Original copyright and licensing notices are retained. See
[provenance](../docs/provenance.md) for direct dependencies, inherited ancestry,
recorded revisions and the original working-tree manifest.

The generic GUI and documentation under docs/upstream are historical reference
paths. They do not replace this edition's root launcher and required game version.
Game data, firmware, caches, optional proprietary DLLs and SDKs are separate.
