# Source export

This directory is a snapshot of the validated DOAX3 working tree, including
its tracked dependency sources and the recorded local VideoOut/FSR changes.
Use the README and Build.cmd at the repository root. The older source README,
generic GUI and archived upstream instructions are historical references.

Dependencies are vendored in this export; no recursive submodule checkout is
needed. See ../docs/provenance.md and ../docs/source-manifest.json for origin,
revision and file hashes. Game data, firmware, SDK binaries and build outputs
are supplied/generated separately.
