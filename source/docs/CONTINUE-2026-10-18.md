## Alterações implementadas

1. **MUBUF addr64**: frontend preserva VGPR[n:n+1] em load/store/atomic; o cálculo compartilhado
   soma soffset e offset imediato com carries separados, sem introduzir IR/int64 nativo novo.
   Flag no bit 25; bit 24 continua `sharp_source`.
2. **V# inline via BDA**, experimental: somente loads raw U32/F32 de 1–4 componentes, V# literal
   com base zero e addr64. Ativo somente com `THEORDER_DIRECT_MEMORY_ACCESS=1`; padrão segue off.
   Alinhamento DWORD ocorre após os carries, conforme Sea Islands §8.1.6. Loads typed,
   swizzled, PC-relative, U8, stores e atomics seguem o caminho anterior.
3. **Sincronização DMA**: uploads aos arenas retornam necessidade de barreira; leituras físicas
   são registradas após draw/dispatch; BDA page table e fault buffer entram no tracker.
   Cobre hazards transfer→shader e shader-read→upload. Sem flush global por draw.
4. **Cache**: versão binária 14 e salt separado para DMA on/off. Primeira sessão recompila
   shaders; isso pode produzir stutter temporário e não deve ser medido como regressão quente.
5. **Testes Vulkan Windows**: ABI Vulkan-Hpp agora usa NDEBUG como a biblioteca, com asserts dos
   testes habilitados depois dos headers. Fixture SlotVector foi adaptada à base 0.20.1.
6. **Fixture scene-resolution**: `ImageInfo ci;` deixava `props` indeterminado. Agora `ci{}`.
   Assertions Windows dos seis testes novos/alterados vão ao stderr, evitando diálogo modal.
7. **Pacote**: refresh de `dist` preserva também `mods_presets.json`. Launcher, README Windows,
   notas e teste de versão declaram 0.6.1.

GDS dinâmico **já estava implementado em 0.20.1**: GetM0 runtime em DS_APPEND/DS_CONSUME.
O teste novo confirma quatro combinações. Não reaplicar o patch antigo d0cfaf355.

### Comandos locais

PowerShell deve colocar `C:\msys64\clang64\bin` e `C:\msys64\usr\bin` no PATH para CMake.
Build: `cmake --build out/gpu --target theorder-probe theorder-gpu-capabilities theorder-play -j 4`.
`bash build.sh` também copia os executáveis para `out/` e gera o stub librsvg.
Suíte: MSYS2 bash, `source ./msys2-env.sh && bash tools/run_tests.sh`.
Python Windows: `out/pyenv/Scripts/python.exe`; base em
`<Windows-Python>/python.exe`.
Empacotar: `WINPYTHON=/path/to/windows-python/python.exe bash packaging/windows/package.sh`.
Use uma única instância de Ninja no mesmo `out/gpu`.
